# PRODIGY_CS_03

## Task 03 - Password Complexity Checker

**Cyber Security Internship @ Prodigy Infotech**

### Description

A simple Python program that checks the strength of a password based on different complexity requirements.

The program checks:

- Password length
- Uppercase letters
- Lowercase letters
- Numbers
- Special characters

It also provides suggestions to improve the password strength.

### Example

```text
===== Password Complexity Checker =====
Enter your password: hello132+

Password Strength: Strong

Suggestions:
- Add at least one uppercase letter.
